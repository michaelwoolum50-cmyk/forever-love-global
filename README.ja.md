# Forever Love — 毎日のカップル向けコンパニオン（日本）

**チェックインして、つながって、一緒に成長しましょう。**

Forever Love は、毎日深くつながり続けたいカップルのための関係アプリです。AI関係コンパニオン「Ember」が、毎日のチェックイン、共有の目標、心のこもった会話であなたの愛を育み、絆を強く保ちます。

## 特徴
- 気分トラッキング付きの毎日の関係チェックイン
- Ember AIコンパニオンによる、あなたに合わせた関係のアドバイス
- 共有の目標設定とマイルストーン管理
- 関係のステージに合わせた会話のきっかけ
- AIが提案するデートナイトプランナー
- ラブランゲージの発見と相性インサイト
- 二人で書くプライベートなカップル日記
- 記念日や特別な日のリマインダー
- 関係ヘルスダッシュボード
